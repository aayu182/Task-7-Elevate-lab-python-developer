# 🖼️ Image Resizer Tool (Task 7)

A simple Python tool that **resizes and converts images in batch**.  
This project is created as part of **Python Developer Internship – Task 7**.

---

## 🚀 Features
- Resize multiple images automatically
- Convert images to any format (PNG by default)
- Handles errors safely using `try-except`
- Works on JPG, JPEG, PNG, WEBP
- Uses `os` for file handling & `Pillow` for image processing
